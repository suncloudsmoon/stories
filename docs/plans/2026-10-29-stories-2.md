# stories 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild `stories` around "one fact, one place": a hook-armed gate, one discipline skill with an on-demand craft file, two procedure skills shared by both homes, anchor citations, and a single `ARCHITECTURE.md`.

**Architecture:** `hooks/stories.py` (stdlib) reads each story's one-line `covers:` and points the model at the covering story on Read, blocks an unannounced edit once, and reminds once at Stop. Skills are prose; Codex symlinks every skill and the hooks dir, so only the two manifests are hand-synced. `scripts/lint-canon.py` stays a dev/CI checker, rewritten around the new conventions, with a `--self-test`.

**Tech Stack:** Markdown skills (YAML frontmatter), Python 3.9+ stdlib, GitHub Actions.

**Spec:** `docs/specs/2026-10-29-stories-2-simplify-design.md` (prior art: `.ref/prior-art/stories-2.md`)

## Global Constraints

- Python stdlib only; must run on Python 3.9 (macOS system `python3`). No new dependencies.
- Hook messages are one line and name the page; never the page body. Any internal hook error exits 0 with no output.
- Skill names: `stories`, `stories-init`, `stories-refresh`. Craft file: `skills/stories/writing.md`. Hook script: `hooks/stories.py`.
- `covers:` is a single-line flow list. Citations are `` `path#anchor` ``; line citations are errors.
- Both manifests → `"version": "2.0.0"`.
- No backwards compatibility with v1 canons or command names.
- Work on branch `stories-2`. **No commit or push without asking the maker** (harness rule) — the final task asks.

## Review Focus

1. **Hook launched from a subdirectory** (event `cwd` = `<root>/src`) — must still find the project root (`CLAUDE_PROJECT_DIR`, else walk up to the dir holding `docs/stories/`). → Task 1 test `subdirectory_cwd`.
2. **Absolute paths and paths outside the project** (Claude Code sends absolute `file_path`) — absolute inside root is relativized; outside root is ignored. → Task 1 test `paths`.
3. **Malformed stdin, missing fields, unreadable story, corrupt state file** — hook exits 0 silently / starts fresh state. → Task 1 test `fails_open`.
4. **Glob edges** — `src/**/x.py` matches `src/x.py`; `*` never crosses `/`; dot-dirs (`.github/**`) match. → Task 1 test `globs`.
5. **Story with no H1** — title falls back to the file stem. → Task 1 test `title_fallback`.

### Task 1: The hook

**Files:** Create `hooks/stories.py`, `hooks/hooks.json`.

**Interfaces — Produces:**
- `Story = namedtuple("Story", "path title globs")` — `path` is root-relative posix (`docs/stories/sagas/x.md`).
- `glob_regex(pattern: str) -> re.Pattern` — `**/` → `(?:.*/)?`, `**` → `.*`, `*` → `[^/]*`, `?` → `[^/]`, everything else escaped; full match.
- `find_root(cwd: str) -> Optional[Path]`
- `load_stories(root: Path) -> list[Story]` — every `docs/stories/**/*.md` whose frontmatter has a one-line `covers:`; title = first `# ` heading, else stem.
- `relative(root: Path, file_path: str) -> Optional[str]`
- `edit_targets(tool_name: str, tool_input: dict) -> list[str]` — `file_path`, `notebook_path`, or every path on `*** Add File: `, `*** Update File: `, `*** Delete File: `, `*** Move to: ` lines of `tool_input["command"]` (apply_patch).
- `handle(event: dict, root: Path, state: dict) -> tuple[int, str, str]` — (exit code, stdout, stderr); mutates `state = {"announced": [], "edited": {}, "touched": [], "reminded": []}`.
- `main() -> int` — reads stdin, loads/saves state at `Path(os.environ.get("CLAUDE_PLUGIN_DATA") or tempfile.gettempdir()) / f"stories-{session_id}.json"`, wraps everything in fail-open `try`. `--self-test` runs the tests below and prints `self-test: N passed`.

Exact copy (spec §4.3):
- Read → stdout `{"hookSpecificOutput": {"hookEventName": "PostToolUse", "additionalContext": "`<file>` is covered by <path> — “<title>”. Read it before you change this file."}}`
- Unannounced edit → exit 2, stderr `Before editing `<file>`, read <path> — “<title>”. Then retry.`
- Stop → stdout `{"decision": "block", "reason": "You changed `<files>`, covered by <path>. If the why changed, rewrite it and set refreshed: to today; if not, you're done."}`
(Several stories → join the `<path> — “<title>”` parts with `; `.)
